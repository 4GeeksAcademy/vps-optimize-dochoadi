[5] RECOMENDACIONES A CORTO - MEDIO Y LARGO PLAZO
------------------------------------------------------------
CORTO PLAZO (inmediato):
  - Actualizar el sistema a mano de forma periódica:
      sudo apt update && sudo apt upgrade
  - Considerar añadir swap (swapfile de 1-2G) para dar colchón
    de memoria si se instalan apps pesadas (bases de datos,
    contenedores, asistentes de IA):
      sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
      sudo mkswap /swapfile && sudo swapon /swapfile
      (persistir en /etc/fstab)
  - No es necesario reinstalar nada: Ubuntu sigue instalado,
    solo se han evitado servicios de segundo plano.
  - Si en el futuro se necesita algún paquete que solo exista
    como Snap, se puede desenmascarar con:
      sudo systemctl unmask snapd.service snapd.socket

MEDIO PLAZO (próximas semanas):
  - Instalar lo imprescindible para la carga objetivo
    (Node, Nginx, Docker, etc.) usando apt/repos oficiales
    en vez de Snap.
  - Poner en marcha un firewall básico (ufw) con reglas
    mínimas y limitar SSH (cambiar puerto o usar keys).
  - Monitorizar RAM/disco con un cron leve o herramientas
    tipo netdata.
  - Evaluar si unattended-upgrades conviene reactivarlo en
    entornos donde no se quiera gestión manual de parches:
      sudo apt install unattended-upgrades
      sudo systemctl enable --now unattended-upgrades

LARGO PLAZO (trimestre):
  - Migrar carga pesada a contenedores (Docker) con límites
    de memoria (--memory) para proteger el host.
  - Si el VPS se queda corto de RAM (1G), plantearse subir a
    2G: con la base optimizada el escalado es mucho más barato.
  - Automatizar el aprovisionamiento (scripts/Ansible) para
    reproducir esta configuración en nuevos droplets.
  - Revisar periódicamente qué servicios están activos
    (systemctl list-units --state=running) para no acumular
    bloat con el tiempo.
